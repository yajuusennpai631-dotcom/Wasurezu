# Wasurezu

宿題・提出物を管理するシンプルなWebアプリです。

## Run locally

Serve `index.html` with any static web server.

## Deploy to Railway

The included Dockerfile serves the app with Nginx on port 80. Connect this repository to Railway and generate a public domain.

Note: tasks are stored in the current browser's localStorage; they are not synced between devices.
